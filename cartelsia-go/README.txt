==================================================
  Cartelsia (Go Standalone Edition v2.1.3)
  Lightweight, portable, high-performance TTS client
==================================================

1. Запуск:
   Двічі клікніть Cartelsia.exe для запуску нативного додатку.
   Консольне вікно приховано завдяки нативній системній підсистемі Windows GUI.
   Інтерфейс відкривається у надшвидкому вікні Microsoft Edge WebView2.

2. Портативність:
   Усі налаштування, ключі API, кеш голосів та аудіо зберігаються поруч у папках
   "data" та "audio".

3. Статистика:
   Всі події синтезу записуються у журнал та автоматично відображаються у вкладці "Статистика"
   з детальною 30-денною історією та розбивкою за ключами.
