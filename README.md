# Cartelsia

Десктопний додаток для озвучення тексту через [Cartesia AI](https://cartesia.ai) з пулом API-ключів. Інтерфейс українською, дизайн у стилі Claude Code Desktop.

![Cartelsia](e2e/.artifacts/04-chunks-done.png)

## Можливості

- **Пул ключів**: додавання вручну (по одному в рядку), імпорт із `.txt`, drag&drop. Авто-перевірка валідності при додаванні (безкоштовний виклик).
- **Локальний облік лімітів**: 20 000 символів/місяць на ключ (можна змінити per-key). Cartesia не віддає залишок через API, тому лічильник ведеться локально й звіряється по помилці `quota_exceeded`.
- **Заморозка ключів**: при залишку < 100 символів або помилці квоти ключ морозиться рівно на **+1 місяць**; біля ключа видно дату/час розморозки. Кнопка «Перевірити» — безкоштовна перевірка валідності або проба генерацією (~1 символ), що розморожує ключ, якщо ліміт скинувся.
- **Розумна розбивка**: текст ділиться на фрагменти (за замовчуванням 500 симв.) по межах речень, без розривів слів. Теги пауз (`<break time="500ms"/>`), сміх, спелінг вставляються кнопками.
- **Паралельна генерація**: до 2 одночасних запитів на ключ (ліміт Cartesia), сумарно 2 × кількість активних ключів. Розкладка чанків по ключах — best-fit: маленькі фрагменти «добивають» майже вичерпані ключі. Якщо фрагмент не влазить у залишок ключа — ключ пропускається, але лишається активним для менших фрагментів.
- **Чати-історія**: кожна генерація — окремий чат зі своїм текстом, налаштуваннями й аудіо. Зберігається назавжди (до видалення чату).
- **Фрагменти**: власний плеєр у кожній картці, редагування тексту, переозвучка зі збереженням **версій** (v1/v2/…, вибір найкращої), ручний ретрай після помилок (авто-ретрай ×3 з ротацією ключів вбудований; помилки не витрачають кредити).
- **«Відтворити все»** — плейліст із підсвіткою поточного фрагмента.
- **«Завантажити все»** — склейка обраних версій в один MP3/WAV з опційною тишею між фрагментами. Є авто-склейка після завершення.
- **Голоси**: пошук/фільтри/прослуховування превʼю/вибране. **Клонування** голосу з файлу або запису з мікрофона (до 10 с). **Локалізація** голосу іншою мовою. Клони привʼязані до акаунта свого ключа — додаток трекає власника і генерує таким голосом лише через нього. ⚠️ Перевірено на живому API (липень 2026): Cartesia вимагає **платний тариф** (від $5/міс) для клонування — на безкоштовному ключі API повертає `plan_upgrade_required`, додаток покаже зрозуміле повідомлення.
- **Субтитр-режим**: генерація з таймкодами слів → експорт SRT/VTT (вмикається в Налаштуваннях; фрагменти зберігаються у WAV).
- **Статистика**: споживання по днях/ключах за 30 днів, історія генерацій.
- **Сповіщення**: системне повідомлення + звук після завершення черги.
- Оцінка перед стартом: скільки символів, як розкладеться по ключах, чи вистачить лімітів.

## Запуск (portable)

`dist/Cartelsia-1.0.0-portable.exe` — один файл без інсталяції. Поруч із ним створюються папки:

- `data/` — налаштування, ключі (**відкритим текстом** — не передавайте цю папку стороннім), чати з аудіо;
- `output/` — збережені файли.

Перше відкриття триває на кілька секунд довше (розпакування) і може показати попередження SmartScreen (файл не підписаний) — «Докладніше» → «Виконати все одно».

## Розробка

```
npm install          # залежності
npm run dev          # dev-режим із HMR
npm run typecheck    # перевірка типів
npm test             # unit-тести (vitest)
npm run smoke        # реальні виклики Cartesia (потрібен keys.local.json)
npm run e2e          # Playwright E2E (потрібен keys.local.json)
npm run build:win    # portable .exe → dist/
```

`keys.local.json` (gitignored): `{ "keys": ["sk_car_...", ...] }`.

Збірка під macOS: на Mac виконати `electron-vite build && electron-builder --mac` (додати `mac.target: dmg` в electron-builder.yml).

## Архітектура (коротко)

- **main** (`src/main`): всі виклики Cartesia (ключі не потрапляють у вікно), пул ключів із заморозкою, черга-scheduler, персистентність JSON, протокол `media://` для стрімінгу аудіо, субтитри, сповіщення.
- **renderer** (`src/renderer`): React + zustand, склейка аудіо через Web Audio + lamejs (без ffmpeg), запис із мікрофона.
- **API**: `Cartesia-Version: 2026-03-01`, `POST /tts/bytes` (mp3/wav), `POST /tts/sse` (таймкоди), `GET/POST /voices*`, `POST /access-token` для перевірки ключів.
