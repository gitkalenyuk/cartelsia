## Швидкий старт

1. **[Скачайте](https://github.com/gitkalenyuk/cartelsia/releases/latest) `Cartelsia-x.x.x-portable.exe`** і покладіть у окрему папку (поруч створяться `data/` і `output/`).
2. Перший запуск: SmartScreen попередить про непідписаний файл → **«Докладніше» → «Виконати все одно»**. Розпакування триває кілька секунд.
3. Вкладка **Ключі** → вставте ключі Cartesia (по одному в рядку) → **Додати**.
   Ключі беруться на [play.cartesia.ai](https://play.cartesia.ai) → API Keys (безкоштовний тариф = 20 000 символів/місяць).
4. **Нова генерація** → оберіть голос (▷ — послухати семпл) → вставте текст → **Озвучити**.
5. Прослухайте фрагменти, переозвучте невдалі, натисніть **«Завантажити все»** — отримаєте один файл.

> ⚠️ Ключі зберігаються **відкритим текстом** у `data/keys.json` поруч із exe — не передавайте цю папку стороннім.

## Автореєстрація акаунтів (v1.4.0)

### Що це

Один клік — і Cartelsia створює вам **до 50 акаунтів Cartesia** з власними API-ключами. Кожен ключ — 20 000 символів/місяць, усі ключі автоматично потрапляють у ваш пул і в `data/accounts.txt`.

Вам не потрібно реєструвати акаунти вручну: бот сам генерує `cartelia_<час>_<рандом>@ваш-домен`, заповнює форму на `play.cartesia.ai/sign-in/create`, ловить **6-значний OTP-код** з пошти по IMAP, вводить його, заходить на `/keys`, створює ключ `sk_car_...` і зберігає `email | пароль | ключ`.

### Як воно працює

```
Налаштування → catchAllDomain + IMAP (Gmail App Password)
        ↓
Браузер → Авторег: обираєте кількість (1–50) → Запустити
        ↓
AutoregService (main) — для кожного cartelia_...@kaleny.uk:
  1) Chromium: відкриває /sign-in/create → заповнює 4 поля → тисне Continue
  2) чекає сторінку /verify-email-address з OTP-полями (до 60 с)
  3) IMAP: кожні 5 с питає пошту — шукає лист СТРОГО для цього email (TO == addr)
  4) витягує код із <b>######</b> (quoted-printable / base64)
  5) вводить код (data-input-otp / autocomplete=one-time-code), Enter
     · якщо Incorrect code — чистить поля, чекає новий лист (до 90 с), вводить повторно
     · якщо лист не прийшов за ~3 хв — акк позначається як помилка і пропускається
  6) якщо WorkOS редіректить на /sign-in?redirect_url — автологіниться email+password
  7) переходить на /keys → Create API key → вписує description → сабмітить 3 шляхами (Enter / клік Submit / Enter на form)
  8) скан 90 с на sk_car_... (input/textarea/code/pre + innerHTML + clipboard)
  9) pool.addKeys([sk_car_...]) — ключ миттєво в пулі + запис у data/accounts.txt і output/accounts.txt
  — пауза 2–6 с між акаунтами (антифрод)
        ↓
Таблиця в Браузері: Email · Статус (У черзі / Форма… / Чекаю листа… / Верифікація… / Створюю ключ… / Готово / Помилка) · Ключ (sk_car_…XXXX) · Помилка, прогрес-бар і кнопка Зупинити
```

Якщо спрацював **Cloudflare Turnstile** — зʼявляється жовтий банер **«Потрібна ручна капча»** з кнопками `Готово, продовжити / Скасувати` (вікно Chromium — клікаєте галочку самі). За бажанням у Налаштуваннях вибираєте **2captcha / CapSolver** і вводите API-ключ капча-сервісу.

### Що таке catch-all і де взяти

**Catch-All** — поштовий трюк: **будь-який** лист на `*@ваш-домен` (наприклад, `as87dashd8@kaleny.uk`, `cartelia_xxx@kaleny.uk`) автоматично **форвардиться на одну пошту** (у прикладі — `nameofsewar@gmail.com`), без створення окремих ящиків.

**Де взяти домен і увімкнути catch-all:**

1. Купіть домен (будь-який реєстратор: Namecheap, Porkbun, Google Domains, nic.ua).
2. Увімкніть **Email Forwarding / Catch-All**:
   - **Cloudflare Email Routing** (безкоштовно): домен на Cloudflare → Email → Email Routing → увімкнути, додати правило `* → ваш-gmail@gmail.com`.
   - Або аналог — у панелі реєстратора/пошти знайдіть перемикач Catch-All → Forward to → ваша Gmail.
3. Після налаштування перевірте: надішліть лист на `test@ваш-домен` — він має впасти у ваш Gmail.

### Де створити ключ для catch-all (покроково)

1. Відкрийте **Cartelsia → Налаштування**.
2. Секція **«Автореєстрація & Catch-All пошта»**:
   - **Catch-All Домен**: `kaleny.uk` (ваш домен без `@`).
   - **IMAP Сервер**: `imap.gmail.com`, **Порт**: `993`, **IMAP Логін**: `nameofsewar@gmail.com` (головна пошта, куди форвардиться catch-all), **IMAP Пароль**: **App Password** (не звичайний пароль Gmail!).
   - Тицьніть **«Перевірити підключення IMAP»** — має показати зелений статус.
   - Нижче — секція **«Налаштування автореєстрації»**: виберіть **провайдера капчі** (Ручна за замовчуванням, або 2captcha/CapSolver + API-ключ), задайте паузу між акаунтами (рекоменд. 2000–6000 мс) і режим Chromium.
3. **Де взяти App Password (Gmail):**
   - Зайдіть на https://myaccount.google.com/apppasswords (має бути увімкнений **2-step verification**).
   - Оберіть додаток **«Пошта»** → пристрій **«Інший»** → назва `Cartelsia` → **Створити**.
   - Скопіюйте 16 символів виду `kvti mrvs iqmr wufe` **з пробілами** — вставте їх у поле IMAP Пароль.
   - Без 2-step версії створити неможливо: https://myaccount.google.com/signinoptions/two-step-verification.
4. Перейдіть у вкладку **Браузер → Автореєстрація**: побачите `Domain: kaleny.uk · IMAP: nameofsewar@gmail.com@imap.gmail.com`.
5. Виберіть `Кількість акаунтів` (1–50) → **Запустити**. Зʼявиться таблиця прогресу; жовтий банер попросить пройти капчу, якщо Cloudflare її вимагатиме.
6. Після завершення перевірте **Ключі** — `+N` активних, і файли `data/accounts.txt` / `output/accounts.txt` з `Email | Pass | Key`.

### Тонкощі

- Кожен акк — унікальний: `cartelia_<час-36>_<рандом>@домен`, пароль `Cartelia_XXXXX##xx!9`. Колізії немає навіть на 50 одночасно.
- OTP шукається **строго по заголовку `TO`**: не по «останньому листу», а саме по конверту цього akka — навіть із сотнею листів у ящику більше не візьме чужий код.
- Якщо **Incorrect code**: поле очищається, бот сам чекає новий лист з іншим кодом (до 90 с) і вводить повторно. Сторінку **не** перезавантажує (раніше — поле пропадало й падав `sign-in?redirect_url`).
- Пауза між акаунтами рандомізується (+до 1 с), щоб не влетіти в rate-limit WorkOS/Cloudflare.
- `accounts.txt` — обидва шляхи: `data/` (поряд із `keys.json`) і `output/` (експорт).

## Свій клон голосу (безкоштовно)

Пряме клонування через API Cartesia відкриває лише на платному тарифі, **але через сайт — безкоштовно**:

1. Зареєструйте окремий акаунт на [play.cartesia.ai](https://play.cartesia.ai) і створіть клон у веб-інтерфейсі (Voices → Clone, кліп до 10 сек).
2. У **тому ж** акаунті створіть API-ключ (клони привʼязані до акаунта — інші ключі їх не бачать).
3. У Cartelsia відкрийте вкладку **«Клон голосу»** → вставте цей ключ як клон-ключ → **«Сканувати клони»**.

Клон-ключі зберігаються окремо від загального пулу і використовуються тільки для озвучення своїми клонами.

## Розробка

```bash
git clone https://github.com/gitkalenyuk/cartelsia.git
cd cartelsia
npm install
npm run dev          # dev-режим із HMR
```

| Команда | Що робить |
|---|---|
| `npm run typecheck` | перевірка типів (main + renderer) |
| `npm test` | unit-тести (vitest): chunker, пул ключів, scheduler, wav |
| `npm run smoke` | реальні виклики Cartesia (потрібен `keys.local.json`) |
| `npm run e2e` | Playwright E2E: повний цикл від ключів до склейки |
| `npm run build:win` | portable .exe → `dist/` |

`keys.local.json` (у `.gitignore`): `{ "keys": ["sk_car_...", "..."] }`

Збірка під macOS: на Mac — `electron-vite build && electron-builder --mac` (додати `mac.target: dmg` в `electron-builder.yml`).

## Архітектура

- **main** (`src/main`) — всі виклики Cartesia (ключі не потрапляють у вікно), пул ключів із заморозкою, черга-scheduler із best-fit розподілом, персистентність JSON, протокол `media://` для стрімінгу аудіо, SRT/VTT, сповіщення; автореєстрація — `ImapClient` (сирий TLS-IMAP, точний `TO`-матч, `quoted-printable/base64`) + `PlaywrightRegistrar` (Chromium 128, анти-детект, 3 шляхи сабміту модалки) + `AutoregService` (черга з подіями `autoreg-progress/done/item-done/captcha`, паузи, `await pool.addKeys`).
- **renderer** (`src/renderer`) — React + zustand, склейка аудіо через Web Audio + lamejs (без ffmpeg), запис із мікрофона, семпл-плеєр; вкладка **Браузер** — жива таблиця автореєстрації, банер капчі, прогрес-бар.
- **API**: `Cartesia-Version: 2026-03-01` · `POST /tts/bytes` (mp3/wav) · `POST /tts/sse` (таймкоди слів) · `GET/POST /voices*` · `POST /access-token` (безкоштовна перевірка ключів).

Перевірені на живому API нюанси: залишок кредитів недоступний через API (ведеться локальний лічильник зі звіркою по `quota_exceeded`); семпли голосів вимагають авторизації; API-клонування на фрі-тарифі повертає `plan_upgrade_required`.
