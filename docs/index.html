Стратегія Catch-All: Нескінченні ключі через піддомени 3-го рівня

Як правильно організувати потік акаунтів, щоб ніколи не платити за озвучку, не витрачати гроші на нові домени та не боятися блокувань від Clerk чи Cartesia.

01

Чому саме піддомени 3-го рівня?

Коли ви реєструєте багато акаунтів на один основний домен (наприклад, *@domain.com), поштовий фільтр антифрод-системи Clerk може внести домен до спам-листа.

Секрет YouTube Cartel: Використовуйте піддомени 3-го рівня: c1.domain.watch, c2.domain.watch, sub.domain.watch. Якщо один піддомен помітять — основний домен залишається чистим! Створення нового піддомену в Namecheap займає 30 секунд і коштує 0$.
02

Рекомендовані дешеві доменні зони (TLD)

Для роботи з Catch-All не потрібно купувати дорогі .com чи .ua. Вибирайте найдешевші зони на Namecheap.com:

.watch (~$1.98) .xyz (~$1.99) .top (~$1.80) .site (~$1.99) .shop (~$1.88) .online (~$1.99) .club (~$1.99)

Один раз купуєте домен за $1.80 на рік і генеруєте з нього тисячі піддоменів та сотні тисяч поштових скриньок без жодних додаткових платежів.

03

Безкоштовний Catch-All через ImprovMX.com

Сервіс ImprovMX.com дозволяє безкоштовно перенаправляти ВСІ листи з будь-якого вашого домену чи піддомену на вашу єдину робочу пошту Gmail.

  • Реєструєтесь на improvmx.com за 1 хвилину (без кредитки).
  • Вказуєте ваш домен або піддомен (наприклад, c1.youtubecartel.watch).
  • Вказуєте адресу призначення (вашу особисту Gmail-скриньку, куди надходитимуть OTP-коди підтвердження).
04

Покрокове налаштування DNS у Namecheap

Відкрийте панель керування доменом у Namecheap ➔ Advanced DNS ➔ Mail Settings. Оберіть Custom MX та додайте наступні записи:

Тип запису Host (Ім'я хоста) Value (Значення) Пріоритет / TTL
MX c1 (або @ для кореня) mx1.improvmx.com. Priority 10
MX c1 (або @ для кореня) mx2.improvmx.com. Priority 20
TXT c1 (або @ для кореня) v=spf1 include:spf.improvmx.com ~all Automatic

🚀 Покроковий алгоритм: створення 50 ключів за 20 хвилин

1
Вигадуєте випадкову пошту на вашому піддомені:

Наприклад, alex9384@c1.youtubecartel.watch. Оскільки увімкнено Catch-All (*), створювати скриньку не потрібно — лист надійде на ваш Gmail автоматично!

2
Реєструєтесь на play.cartesia.ai:

Вказуєте пошту. Лист з 6-значним OTP-кодом надходить у вашу Gmail скриньку через 1–2 секунди. Вставляєте код — акаунт готовий!

3
Створюєте API Key:

Переходите у Settings ➔ API Keys, натискаєте Create New API Key і копіюєте ключ формату sk_car_....

4
Вставляєте ключ у Cartelsia:

Відкриваєте вкладку «Ключі» у Cartelsia, натискаєте «+ Додати ключ» або вставляєте список з 50 ключів оптом. Cartelsia миттєво валідує кожен ключ і об'єднує їх у спільний пул символів!

ЗАПУСК ЗА 2 ХВИЛИНИ

Посібник користувача

Оберіть вашу ОС та дізнайтесь про всі деталі налаштування

1
Завантажте архів:

Отримайте Cartelsia-Go-v2.2.0-windows-x64.zip та розпакуйте його в будь-яку теку (наприклад, C:\Cartelsia або на робочий стіл).

2
Запустіть Cartelsia.exe:

Двічі клікніть по Cartelsia.exe. Завдяки прапору -H=windowsgui чорне вікно командного рядка не з'являється — застосунок стартує миттєво у нативному елегантному вікні.

3
Вставте ключі та почніть озвучення:

Перейдіть у розділ «Ключі», вставте ваші API-ключі. Створюйте чат, обирайте голос і насолоджуйтесь якістю!

1
Завантажте відповідний архів для Mac:

Для чипів M1 / M2 / M3 / M4 — Cartelsia-Go-v2.2.0-mac-arm64.zip. Для процесорів Intel — Cartelsia-Go-v2.2.0-mac-amd64.zip.

2
Зніміть блокування Gatekeeper:

Відкрийте Terminal у розпакованій папці та виконайте команду:

xattr -cr . && chmod +x Cartelsia run.sh
3
Запустіть скрипт:
./run.sh

Застосунок підніме швидкісний локальний веб-сервер та відкриє інтерфейс у вашому браузері.

⚡
Автоматична ротація при вичерпанні ліміту:

Коли на одному з ключів закінчуються безкоштовні 20 000 символів, Cartelsia автоматично позначає його та перенаправляє чергу чанків на наступний активний ключ. Жоден фрагмент аудіо не губиться!

🔄
Кешування згенерованих фрагментів:

Якщо ви змінили одне слово у середині 10-хвилинного тексту, Cartelsia переозвучить лише змінений фрагмент, заощаджуючи ваші символи.

ПОРТАТИВНІСТЬ

Структура даних та збереження

Повна автономність: усі файли зберігаються поруч із програмою.

📁 Папка data/

Усе ваше налаштування, історія та ключі:

  • keys.json — база ваших API-ключів та лічильники використаних символів.
  • settings.json — дефолтні налаштування моделі, формату аудіо та IMAP.
  • shared_voices.json — реєстр доданих спільних голосів за Voice ID.
  • chats/ — тексти та згенеровані аудіо-чанки.

🎧 Папка output/

Готові аудіофайли для ваших відео:

  • Склеєні повнорозмірні аудіотреки у форматі .mp3 або .wav.
  • Файли субтитрів .srt та .vtt з точними таймінгами слів.
  • Прямий доступ до результатів без зайвих меню.
