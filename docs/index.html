📮 Catch-All на субдомені (щоб основний домен не банили)

Всі реєстрації йдуть на *@ваш-домен. Якщо Cartesia забанить домен — все пропало. Тому реєструйте на СУБДОМЕНІ: reg.mydomain.com. Забанили субдомен? Міняєте на reg2.mydomain.com за 2 хвилини, основний недоторканим.

Через ImprovMX (безкоштовно, 5 хв)

  1. Зареєструйтесь на improvmx.com → Add Domain → введіть reg.mydomain.com.
  2. В DNS додайте записи (ImprovMX їх покаже):
    MX reg → mx1.improvmx.com (пріоритет 10)
    MX reg → mx2.improvmx.com (20)
    TXT reg → v=spf1 include:spf.improvmx.com ~all
  3. Forward to: ваша Gmail. Wildcard (будь-що@sub) включено за замовчуванням.
  4. У Gmail зробіть фільтр: To contains @reg.mydomain.com → Never spam (щоб OTP не падав у спам).
  5. Тест: надішліть лист на xyz@reg.mydomain.com — має прийти в Gmail.
  6. Cartelsia → Налаштування → Catch-All домен = reg.mydomain.com.
💡 Кілька субдоменів = кілька незалежних партій: reg1.mydomain.com і reg2.mydomain.com. Основний домен ніколи не світиться в реєстраціях.

🌐 Спільні голоси за Voice ID (2.1.0)

Будь-який публічний («Shared») голос Cartesia можна додати за Voice ID — і озвучувати ним УСІМ пулом безкоштовних ключів. Кредити списуються з вашого ключа, не з акаунта власника (перевірено наживо).

Як зробити свій клон спільним і юзати його free-ключами

1
Створіть клон на сайті
play.cartesia.ai → Voices → Clone voice: аудіо до 10 секунд (файл або мікрофон). Безкоштовно.
2
Увімкніть Share → Shared
У картці клона натисніть Share, оберіть Shared — «Anyone with the voice ID can use it». Це те саме, що PATCH access=public по API.
3
Скопіюйте Voice ID
У тому ж діалозі Share є поле ID — рядок виду afe1bd4e-954e-48cc-8225-22c0… Це ключ доступу до голосу.
4
Додайте в Cartelsia
Вкладка «Клон голосу» → блок 🌐 Спільні голоси → вставте ID + придумайте аліас (наприклад don-pedro) → «Додати». Cartelsia перевірить голос через API і збереже ярлик у data/shared_voices.json.
5
Озвучуйте всім пулом
Голос зʼявиться в композері (секція «Спільні голоси»). Обери його — і генерація піде звичайними БЕЗКОШТОВНИМИ ключами: 100 тис. символів розподіляться по всіх free-ключах по ~20 тис., але озвучаться ОДНИМ голосом. Кредити власника не горять.
МеханізмЯк працює
Хто платить кредитиТой, чиїм ключем робиться запит TTS. Власнику публічного voice_id — нічого. Перевірено живим викликом чужим free-ключем
Чому «ярлик», а не копіяAPI Cartesia НЕ вміє копіювати/імпортувати чужі голоси (офіційно підтверджено). Cartelsia зберігає alias → voice_id локально; нічого в Cartesia не пишеться
Захист від ревокаціїВласник може вимкнути Shared будь-якої миті. Перед КОЖНИМ прогоном голос re-verifiкується (GET /voices/{id}); відкликаний → прогін ЧЕСНО зупиняється з назвою аліаса, НІКОЛИ не мовчки озвучує іншим голосом
Кеш TTSsha256(voice+model+language+text) → data/tts-cache/. Переозвучка того самого тексту = 0 кредитів, миттєво. Атомарний запис (tmp→rename) переживає crash
PVC-голоси 👑Pro Voice Clones мають обмеження моделей (fine_tunes[].public_model_id); невідповідна модель → voice_model_mismatch із чітким повідомленням

👑 Master-клонування голосів (2.0.1)

Один Pro-акаунт ($5/міс) = необмежені голосові клони для ВСІХ ваших безкоштовних ключів. Клони живуть на мастер-акаунті, але після публікації доступні будь-якому ключу.

1
Додайте Master API-ключ
Налаштування → Master-акаунт → вставте ключ Pro-акаунта → «Перевірити». Він зберігається окремо від пулу і не витрачається на звичайні генерації.
2
Створіть клон
Клон голосу → Master-секція → аудіо файлом або запис із мікрофона (до 10 с). ffmpeg сам обрізає тишу та нормалізує гучність.
3
Голос публікується автоматично
PATCH access=public одразу після клонування — інакше чужі (free) ключі його не побачать. Можна вимкнути в Налаштуваннях.
4
Озвучуйте free-ключами
Публічний master-клон вибирається у VoicePicker як звичайний голос — генерація йде через будь-який активний ключ пулу, без списання з Pro.
МеханізмЯк працює
ffmpeg-препроцесингОбрізання тиші (−45 dB), loudnorm I=−16/TP=−1.5/LRA=11, mono 44.1 kHz s16, жорсткий cap 10 с
ДедуплікаціяSHA-256 обробленого аудіо = первинний ключ реєстру data/master_voices.json: те саме аудіо ніколи не клонується двічі
Автоповтори429/5xx повторюються ×5 (exponential backoff + jitter), інші 4xx показуються одразу; ліміт паралельності Free 2 / Pro 3 / Startup 5 / Scale 15
Crash-safetyРеєстр пишеться ДО публікації; синхронізація GET /voices?is_owner=true підтягує голоси, якщо локальний файл загублено
💡 Потрібен ffmpeg у PATH або поруч із exe — лише для клонування. TTS і автореєстрація працюють без нього. Без Pro-акаунта всі функції 2.0 далі працюють як раніше.

❓ FAQ

Чому максимум 25 потоків?
При >25 одночасних Clerk/Vercel масово віддають HTTP 429, checkpoint не проходить — фейли лавиною. 5–15 стабільно, 25 межа.
Чому частина фейлиться навіть так?
Повільні проксі не встигають за 90 с + OTP-листи затримуються. Retry з новим проксі + rescue добирає більшість. Знизьте потоки до 10–15 — успішність зросте.
Акаунт без ключа — загублено?
Ні. Rescue-прохід після прогону сам відновлює сесію з sessions/ та витягує ключ. Дані про всі акаунти — в accounts.txt.
Чому не просто залогінитись знову за ключем?
Clerk Bot Protection: логін паролем з нового браузера = protect-check, «suspicious blocked». Тому ключ береться одразу в сеансі реєстрації, а сесія зберігається.
OTP не знаходиться
Перевірте: Gmail App Password (не звичайний пароль), forwarding працює (тестовий лист на xyz@sub.domain.com приходить у Gmail), фільтр Never spam додано.
Домен баниться?
На субдомені — тільки він. Змінюйте reg. → reg2. в ImprovMX та в Налаштуваннях Cartelsia. Основний домен живе.
Антивірус лається на exe
Portable самопідписаний — SmartScreen попереджає всі непідписані. Код відкритий: зберіть самі або скористайтесь AI-промптом.
macOS?
Технічно переноситься (Electron+Playwright). Збірка на Mac: npm install && npm run build && npx electron-builder --mac. Або AI-промпт нижче — він сам розбереться.
