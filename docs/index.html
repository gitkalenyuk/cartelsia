Потужний інструментарій для контент-мейкерів

🔑

Пул ключів (500+)

Скільки завгодно безкоштовних ключів. Best-fit алгоритм розподілу: кожен фрагмент тексту йде на ключ із найменшим достатнім залишком символів. Авто-заморозка вичерпаних ключів.

⚡

Паралельна Go-генерація

Чанки тексту озвучуються паралельно через горутини на різних ключах. Автоматичні повтори при збоях, вбудований кеш — повторна озвучка фрагмента взагалі не витрачає API.

🌐

Спільні голоси

Будь-який публічний голос Cartesia додається за Voice ID у твою бібліотеку в один клік. Озвучуй ним усім пулом: символи списуються з твоїх ключів, а не з власника голосу.

👑

Master-клонування

Pro-акаунт ($5) перетворюється на фабрику клонів: автоматичне обрізання тиші, нормалізація гучності, автопублікація та дедуплікація SHA-256 для економії балансу.

🎯

Субтитри SRT/VTT

Послівні таймкоди від моделі sonic-3.6. Автоматичний експорт готових синхронізованих субтитрів разом із зведеним аудіотреком.

🛡️

Проксі 2.0 & Захист

Realtime-перевірка досяжності доменів Cartesia. Розумне балансування запитів та захист від троттлінгу з'єднань.

Детальні інструкції із запуску

Оберіть вашу платформу та почніть озвучення за пару хвилин

1
Завантажте та розархівуйте:

Завантажте Cartelsia-Go-v2.1.3-windows-x64.zip та розпакуйте його у будь-яку зручну папку на диску.

2
Запустіть Cartelsia.exe:

Двічі клікніть по Cartelsia.exe. Якщо на вашому ПК встановлено Edge WebView2 (є за замовчуванням у Windows 10/11), відкриється нативне вікно застосунку. Якщо ні — автоматично відкриється сторінка у вашому браузері.

3
Додайте ключі та озвучуйте:

Перейдіть у розділ «Ключі», вставте ваші API-ключі або імпортуйте текстовий файл. Готово! Ваші налаштування зберігатимуться у папці data/, а аудіо — у output/.

1
Оберіть правильний архів:

Для Mac з чипами M1 / M2 / M3 / M4 завантажте Cartelsia-Go-v2.1.3-macOS-arm64.zip. Для моделей на Intel — Cartelsia-Go-v2.1.3-macOS-x64.zip.

2
Зніміть карантин macOS (Gatekeeper):

Оскільки це портативний білд без платного підпису Apple Developer, відкрийте Terminal у папці застосунку та виконайте:

xattr -cr . && chmod +x Cartelsia run.sh
3
Запустіть скрипт:
./run.sh

Сервер Cartelsia підніметься на http://127.0.0.1:54321 і відкриє інтерфейс у вашому Safari або Chrome.

💡
Важливе роз'яснення щодо реєстрації та акаунтів Cartesia:

Пряма програмна автореєстрація через сторонні скрипти або IMAP наразі заблокована на рівні Cloudflare/Turnstile захисту платформи Cartesia.

✅
Як правильно отримувати ключі без банів:

Найбезпечніший, стабільний і перевірений спосіб: відкрити офіційний сайт play.cartesia.ai у браузері і просто увійти через кнопку Continue with Google.

  • Google OAuth пропускає будь-які капчі без ризику блокувань.
  • Ніколи не вводьте номери телефонів у форми виклику IAP — звичайний Google-вхід створює акаунт миттєво.
  • Отриманий безкоштовний ключ додайте у розділ «Ключі» в Cartelsia — він одразу додасться до вашого пулу.

Часті питання (FAQ)

Яку версію краще обрати — Go чи Electron?

Для більшості користувачів ми рекомендуємо нову Go Standalone версію: вона важить лише ~12 МБ (проти 121 МБ), стартує миттєво, не вантажить процесор та оперативну пам'ять і доступна як для Windows, так і для macOS. Класичний Electron білд збережено для тих, хто звик до старого формату.

Чи безпечно використовувати пул ключів?

Так, Cartelsia працює через офіційний Cartesia REST API. Запити балансуються за принципом best-fit, тож ключі не спаляться і не перевантажуються.

Як додати свій клон голосу на всі ключі?

Створіть клон один раз (наприклад, на Pro-акаунті або через діалог клонування), скопіюйте Voice ID і додайте його у розділ «Спільні голоси». Після цього будь-який ключ вашого пулу зможе генерувати мовлення цим голосом.

Що робити, якщо SmartScreen лається на Windows?

Портативні збірки без платного сертифіката Microsoft викликають звичайне попередження SmartScreen. Натисніть «Докладніше» → «Виконати у будь-якому разі». Код програми повністю відкритий на GitHub.

Як перенести ключі зі старої версії у нову?

Просто скопіюйте файл keys.json з папки data/ старої версії у папку data/ нової версії Cartelsia Go.

Готовий озвучувати безкоштовно?

Нативне ядро Go. 12 МБ. Повний контроль над генерацією аудіо.
