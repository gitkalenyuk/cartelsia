# Cartelsia 2.0.1 — Master-клонування голосів

**Дата:** 27.08.2026

## Суть релізу

Один платний акаунт (Pro за $5/міс) стає «фабрикою голосів»: через його API-ключ
створюються клони, голоси автоматично публікуються — і далі озвучуються
безкоштовними ключами пулу (включно з ключами з автореєстрації 2.0).

## Що зроблено

### 👑 Master-акаунт (Налаштування → Master-акаунт)
- Поле **Master API-ключ**: ключ акаунта з Pro-підпискою; зберігається локально
  (`data/settings.json`), ніколи не додається в загальний пул і не використовується для звичайних генерацій.
- Кнопка **Перевірити ключ** — валідація через `POST /access-token`.
- **Авто-публікація** (default ON): після клонування PATCH `/voices/{id}` `access=public`
  → голос доступний усім іншим ключам.
- **Ліміт паралельності**: Free 2 / Pro 3 / Startup 5 / Scale 15 (default Pro=3);
  перевищення супроводжується автоповторами.

### 🎙️ Клонування по API (Клон голосу → Master-секція)
- Вибір аудіо файлом або запис із мікрофона (до 10 с).
- **ffmpeg-препроцесинг** перед відправкою:
  - обрізання тиші на початку/кінці (`silenceremove` ±45 dB) та скорочення внутрішніх пауз;
  - loudness normalization `loudnorm I=-16:TP=-1.5:LRA=11`;
  - конвертація в mono 44100 Hz PCM s16 (WAV), жорсткий cap 10 с.
  - *Перевірено наживо: 5 с кліп (1 с тиша + 3 с тон + 1 с тиша) → 3.20 с чистого сигналу.*
- Multipart `POST /voices/clone` (clip + name + language + description + access).
- Валідація accent через `GET /accents` (якщо заданий вручну).

### ♻️ Дедуплікація і гарантії цілісності
- SHA-256 хеш обробленого аудіо як первинний ключ реєстру `data/master_voices.json`.
- Повторний клонування того самого аудіо повертає вже створений voice_id (ніколи не списує кредити двічі).
- Якщо голос на боці Cartesia видалено — автоматичне переклоновування.
- Реєстрація пишеться ДО публікації: crash між кроками не створює дублікатів.

### ⚖️ Робота з помилками API
- Автоповтори 429/5xx/мережевих: ×5 спроб, exponential backoff (800 мс → 15 с) + jitter ±25%.
- Інші 4xx НЕ повторюються (auth/quota/bad_request показуються одразу, включно з `plan_upgrade_required`).
- Кожна помилка містить `request_id`, якщо API його віддав.

### 🔗 Інтеграція в пайплайн TTS
- Master-клони видно у вкладці «Клон голосу» (значок 👑) та в VoicePicker композера.
- При виборі публічного master-клона генератор використовує будь-який активний free-ключ пулу —
  без пінгування ключа-власника.
- Перемикач публічності 👁 прямо на картці клона.

## Технічні деталі

| Файл | Роль |
|---|---|
| `src/main/voices/masterVoiceService.ts` | нове: вся логіка master-клонування (дедуп, семафор, retry, ensurePublic) |
| `src/main/cartesia/retry.ts` | нове: withRetry (429/5xx only, backoff+jitter) |
| `src/main/audio/preprocess.ts` | нове: ffmpeg-препроцесинг + sha256Hex |
| `src/main/cartesia/client.ts` | + getVoice, updateVoice, getAccents; cloneVoice тепер приймає accent/access/tagline |
| `src/main/ipc/handlers.ts` | канали master:status/clone/togglePublic/list |
| `src/renderer/.../CloneVoiceView.tsx` | MasterCloneSection + діалог клонування |
| `src/renderer/.../SettingsView.tsx` | секція Master-акаунта з підказками |

## Тести

- 120 unit-тестів (vitest) — всі зелені, з них 6 нових: retry (3), статус master-ключа (2), SHA-256 дедуплікація end-to-end (1).
- typecheck main+renderer чистий.
- Живий ffmpeg-пробій підтвердив обрізання тиші та нормалізацію формату.
